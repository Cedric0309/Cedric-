# Cedric-

Créer le site internet du Cabinet BNS Conseil.

## Accéder au site

Ce projet est un site statique. Pour le visualiser localement et obtenir une URL accessible depuis votre navigateur :

1. Assurez-vous d'être dans le dossier du projet :
   ```bash
   cd /workspace/Cedric-
   ```
2. Lancez un petit serveur web local (par exemple avec Python) :
   ```bash
   python3 -m http.server 8000
   ```
3. Ouvrez votre navigateur et rendez-vous sur :
   ```
   http://localhost:8000/index.html
   ```

Pour partager le site en ligne, vous pouvez également publier ces fichiers sur un service comme GitHub Pages, Netlify ou Vercel qui vous fournira un lien public.
